# Naming Ceremony Invitation

A responsive web invitation for a naming ceremony, built with React, Vite, TypeScript, and Tailwind CSS.

## Features

- Animated hero section & countdown timer
- Event schedule & venue location with map
- Photo gallery with upload support
- Send wishes form
- Background music player
- Fully responsive design

## Getting Started

```bash
cd naming-ceremony
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build
```

Deployed automatically to GitHub Pages via `.github/workflows/deploy.yml`.

## Tech Stack

- **React 19** + **TypeScript 6**
- **Vite 8** (bundler & dev server)
- **Tailwind CSS 3** (styling)
- **Framer Motion** (animations)
- **React Router** (HashRouter for GitHub Pages)
